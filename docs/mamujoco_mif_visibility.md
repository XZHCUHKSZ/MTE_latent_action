# MIF：遮蔽是否改变 Möbius 的相对控制收益？

2026-09-19 用户授权的后续配对。正式输出 `outputs/mamujoco_mif_visibility_2026_09_19`。

## 要回答的问题

前轮 full-visibility route 中 MIF−raw 的五种子均值为负。它与论文主 MIF 协议不仅可见性不同，batch、学习率调度及重建损失也不同，不能跨两轮相减就把差异归因于遮蔽。本实验在原 MIF 训练设置内交叉改变坐标和编码器可见性。

四组为 masked_mobius、masked_raw、visible_mobius、visible_raw。全部使用同一观察导出、修复后端点、实体投影、训练归一化和参数初始化。raw 仅将已有模型的 Möbius/zeta 固定缓冲矩阵设为单位阵，不更改传播图、网络宽度或历史模型。

## 原方法的准确含义

原 MIF 在变换后的坐标节点上随机遮蔽30%，保留第一预测时域的空子集边界。它不是先删除原始预测表项再变换。两种坐标使用相同节点索引掩码，不等于删除相同的原始表信息；这里检验的是坐标组织与该训练机制的组合。

Simple/Graph 原训练没有这种随机遮蔽，而有系数重建加差分表重建。本轮不创建冒充原模型的 masked Simple/Graph。之前将全部主方法笼统称为 masked 协议不准确。

原 MIF 的 loss 为被选中隐藏索引处的重建MSE，加0.25倍其余索引MSE，加方差下限及0.02倍协方差惩罚。visible 两组保留完全相同的随机 loss 分组、权重和随机数消耗，仅让编码器看到全部坐标。这样改变的是编码器可见性，而不是同时改变损失。它与前轮 route 的整表MSE协议有明确区分。

## 固定规模与实现

- 既有数据/前端种子0–4，N90，MIF-Aux；Base与辅助分支各16维。
- 四组×五种子，共20个表示/历史配置。表示3200更新、batch512、hidden108、原Adam1e-3及warmup/decay；历史1200更新。
- B4/8/16/32/64；decoder重复202609160–164，每次800更新。
- 每单元50个共同episode、上限200步；共500组新控制结果，不混入前轮不同协议。
- 两路预训练，全部冻结后四路grounding。任务边界可暂停续跑；不覆盖partial。
- 通过 `training/mif_visibility_control.py` 对现有 `mte.structured_controls.train` 的模型构造加显式、进程内作用域适配。原科学类、训练函数、损失和受保护文件均不修改。native组不改变任何模型输入。

## 验收

先做四路径冒烟：2更新、2episode×5步，不用冒烟成绩选择协议。额外用小数组验证 native adapter 与无adapter的原训练器权重和latent逐项一致。

正式grounding前核对四组参数量、初始化、训练归一化与完整loss掩码序列哈希一致；核验raw单位矩阵。五个 masked_mobius 表示/历史权重还必须与已接受 repaired 归档逐项比较，最大误差阈值1e-5。出现不符先停止新派发并检查，不将不同协议冒充复现。

每个预训练worker只允许无标签观察与预测端点；先冻结所有历史权重，再开放动作预算文件和模拟器。完成须500唯一单元、来源和freeze指纹一致、访问审计无违规及foundation verifier通过。

## 预定分析

每个上游种子内平均全部五预算及五decoder重复，得到四个回报。三个预定配对为：

1. masked 下 Möbius−raw。
2. visible 下 Möbius−raw。
3. 差中之差：(Möbius−raw)masked−(Möbius−raw)visible。

第三项为正说明在这些设置中，遮蔽提高了Möbius相对于raw的控制表现；仅一组正、另一组负本身不替代该配对检验。三个检验放在同一Holm族，报告五个上游seed的精确双侧符号置换p和描述性t95区间，全部预算和正负结果保留。五seed最小精确p为0.0625，不把decoder重复当独立上游种子。
